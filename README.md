I build open-source infrastructure, developer tools, and systems software. I prefer small, auditable codebases, proven engineering, and simple architectures that are easy to understand and maintain.

**Build from first principles. Reuse what works. Own what matters.**

## Philosophy

* **Open source first.** Prefer free, auditable software. Read the code before trusting it.
* **Battle-tested over novel.** Choose proven tools, libraries, and test suites over novelty for its own sake.
* **Own the implementation.** Build core components from scratch when doing so improves control, clarity, or performance — from parsers and encoders to hash tables and network stacks.
* **Minimal runtime dependencies.** Prefer single-binary tools with no external runtime dependencies.
* **AI-first codebases.** Design consistent, compact architectures that humans and LLMs can understand, navigate, and extend.
* **Performance through simplicity.** Optimize hot paths, minimize allocations, and verify improvements with reproducible benchmarks.
* **Security by design.** Reduce attack surfaces, understand trust boundaries, and make systems easier to audit.
* **Ship, measure, iterate.** Build practical solutions, validate them, and improve them in the open.
